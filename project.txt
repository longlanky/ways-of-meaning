Goal:
Create a fast command-line / TUI semantic search engine for linux called "Ways of Meaning", which is invoked with the comand "wom"

-----
Example command and possible returned results:
```
wom employment documents

directory:employment_docs, 2024_W2.pdf, procedural_notes.txt, 2023_w2.pdf, 1092.pdf
```
Or:
```
wom bosnia

directory:bosnia_croatia_trip_aug2024, dubrovnik_to_sarajevo.pdf
```
Or:
```
wom ~/projects/ sensors monitor

D:-/2026_esp32epaper_display/esp32_prayerTimesWithWeather_n5endpoint/src/main.cpp
-----

Details:
1. User specifies directories to index either by common directories (e.g. xdg convention like Documents,Photos,Videos,Desktop... excluding places like ~/.cache or similar directories) and or specific directories
2. Data is stored locally in a sqlite database
3. Dataset is defined in an initial run, and then deltas are refreshed on a specified schedule (e.g. on every run check for changes, once a day check for changes, once a week)
4. results returned can be moved through with the keyboard and when a specified file or directory is selected, the user can press a button "d" for example to open the directory in the a terminal, "e" to open in editor in terminal, or "x" to open using xdg prompt when applicable in a desktop environment, "s" to save results in a text file, "Z" or "esc" to exit
5. I would like to use the model at this link as it is highly regarded for accuracy and semantic meaning "https://huggingface.co/BAAI/bge-large-en-v1.5/tree/main", if not, then all-MiniLM-L6-v2 https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2
6. GPU acceleration if possible
